# Flat Hunt Phase 3 (Area Analysis) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every listing with coordinates gets sourced area facts, computed on the server in the background: everyday places within walking distance (OpenStreetMap), mapped flood hazard (BfG, nationwide), mapped noise (NRW and Berlin), recorded crime of the Kreis against the national rate (BKA PKS 2025), the census rent of the surrounding 1 km square (Zensus 2022) and the price per m² against the other tracked listings. The listing detail shows them in an "Area" panel, the card shows flood and noise badges, the `area` rating gets a transparent estimate, and a footer credits every source.

**Architecture:** Phase 1's `createApp` stays the entry point. One module per source, each a pure parser plus one fetch function with stubbable `fetchImpl`: `lib/kreis.js` (BKG VG250 WFS), `lib/flood.js` (BfG NZ identify), `lib/noise.js` (state adapters for the NRW and Berlin WMS), `lib/amenities.js` (Overpass + FOSSGIS foot table) with `lib/area-cache.js`, and two static lookups `lib/crime.js` (PKS JSON) and `lib/rent-grid.js` (Zensus grid). `lib/area-http.js` holds the polite HTTP layer (User-Agent, timeouts, back-off, minimum spacing). `lib/area.js` combines the sources into the listing's `area` object; `lib/area-job.js` runs one listing at a time in the background; `lib/area-api.js` adds the queue and on-demand routes. Static files in `lib/data/` are produced by `scripts/area-data.js` from the official downloads. The page gets `public/area-sources.js` (source catalogue, shared with Node) and `public/area-ui.js` (panel, badges, footer); the rating and the price check live in `public/criteria.js`.

**Tech Stack:** Node ≥ 18, Express 4, Node built-ins only for the new code (`zlib` for the zip/xlsx reader and the gzip grid), plain browser JavaScript, `node --test`.

**Spec:** `docs/design.md` (section "Area analysis (phase 3)", rewritten by Task 9), the phase-3 data spike of 19.10.2026 (live-tested sources, URLs, licences and failure modes; its findings are summarised in the Global Constraints and the source modules), plus the decisions below.

## Global Constraints

Carried over from phases 1 and 2:

- No personal data in the repository. Before every push: `grep -rn -i -f "$PATTERNS" --exclude-dir=node_modules --exclude-dir=.superpowers . || echo clean` must print `clean` (`$PATTERNS` is a private file outside the repo). Tests and examples use only "Alex Example", "alex@example.com", "Beispielstraße 1, 40210 Düsseldorf", "Example GmbH" and public landmarks (Königsallee, Berlin Mitte).
- Commits use the repo-local no-reply author already configured; no AI attribution lines.
- Node ≥ 18. Runtime dependencies stay `express` and `pdf-lib`; phase 3 adds no npm package (scripts included).
- All user-facing text in English (`en`), German (`de`) and Brazilian Portuguese (`pt`).
- `SITE_PASSWORD` required to start unless `ALLOW_OPEN=1`. Public routes stay `/healthz` and `/s/*`; the new routes need the password.
- Writes to `DATA_DIR` are atomic; failed saves roll back in-memory changes.

New in phase 3:

- **Never in the request path.** No request handler awaits an area source. Adding a listing, changing its address (page or routine) and starting the server queue work in `lib/area-job.js`; the queue handles one listing at a time. On-demand recompute (`POST /api/listings/:id/area`) only queues and answers 202.
- **Polite HTTP.** Every area request sends `User-Agent: flat-hunt/0.1 (+https://github.com/DasMehl/flat-hunt)` (the constant from `lib/geo.js`) and has a timeout (Overpass 60 s, foot router and WFS/WMS 10 s, BfG 15 s). Overpass: at most one query at a time, at least 10 s between queries (`overpassSpacingMs`), retries after 30, 60 and 120 s on 429/502/503/504, timeouts, network errors and a "runtime error" remark, honouring a longer `Retry-After` (capped at 10 min). Other sources: one retry after 2 s. 4xx answers other than 429 are not retried. One Overpass query and one foot-router `table` call per listing; Overpass results are cached 30 days by position rounded to 3 decimals (about 100 m) in `DATA_DIR/area-cache.json` (newest 500 entries); on-demand recompute skips the cache. Optional `OVERPASS_URL` points at another (e.g. self-hosted) Overpass instance.
- **The `area` object** (listing field, written only by the server; `area` is removed from the routine's `LISTING_FIELDS`):
  ```js
  area = {
    lat, lon, computedAt,                                   // the coordinates it was computed for
    kreis:     { status, source: "bkg-vg250", level: "point", fetchedAt, ags, name, type },
    flood:     { status, source: "bfg-nz", level: "point", fetchedAt, zones: ["high"|"medium"|"low"…], worst, dataYear: 2019 },
    noise:     { status, source: "nrw-noise"|"berlin-noise"|null, level: "point", fetchedAt, state, lden: { road, rail?, tram, air, industry }, max, band, dominant, dataYear: 2022 },
    crime:     { status, source: "bka-pks", level: "kreis", fetchedAt, ags, kreis, kind, year, hz: { total, violent, street, burglary }, national: {…}, ratio: {…} },
    rent:      { status, source: "zensus-rent", level: "cell-1km", fetchedAt, cell, eurPerSqm, year: 2022, refDate: "2022-05-15" },
    amenities: { status, source: "osm", level: "walk", fetchedAt, routing: "osm-foot"|"estimate", cached, items: { transit, supermarket, pharmacy, doctors, kindergarten, school, park, playground } }
  }
  // item = { name, minutes, meters, estimated, lines?: [{ ref, mode }] } or null (none within 1 km; stops: 500 m)
  // failed figure = { status: "error", source, level, fetchedAt, error: "HTTP 503" | "timeout" | "request failed" | "Kreis unknown" | "rent grid missing" | "crime table missing" }
  ```
- **Status semantics.** `ok` = the source answered with a value; `no-data` = the source has nothing for this point; `error` = the lookup failed. `no-data` is never shown as "safe" or "no risk": an empty BfG answer means "no mapped flood area found here (coverage not guaranteed)", a state without a noise adapter means "no noise data", a noise answer without any mapped source means "no mapped source at or above 55 dB(A)", not "quiet".
- **Crime** is shown only as the Kreis rate compared with the national rate, with fixed wording that it is an area average counted where crimes happen and says nothing about a street. It is never shown on cards, never coloured as good/bad, and never turned into a per-street score; in the area rating it can deduct at most 1 point (Task 7).
- **Every figure shows** its source name, area level, data year or reference date and the retrieval date; a page footer lists all sources with licence and attribution (`public/area-sources.js`). BfG's attribution carries the retrieval date, BKG's the retrieval year.
- **Static data** lives in `lib/data/` (tracked: `.gitignore` changes `data/` to `/data/`), is produced only by `scripts/area-data.js` from the official files and never edited by hand. Every generated file carries `_source`, `_licence`, `_attribution`, `_changes` and `_generated` (the grid's header is its JSON sidecar). Size limits enforced by the script: PKS JSON ≤ 100 KB, Zensus grid ≤ 1.5 MB.
- **Tests never hit the network.** Every fetch is stubbed; `test/helpers.js` `start()` passes `areaAuto: false`, so phase 1 and 2 tests start no background lookups.
- New `createApp` options (tests): `areaAuto` (default `true`: queue on add/move and backfill at start), `area: { crimeTable, rentGrid, overpassUrl, overpassSpacingMs (default 10000), delays, overpassDelays, sleep }`. New `app.locals.areaQueue`.

## Decisions for phase 3

| Topic | Decision |
|---|---|
| Amenities | Overpass (one combined query: categories within 1 km, platforms within 500 m, their route relations with `out body`), foot `table` for the nearest 3 per category; straight line × 1.3 at 80 m/min when the foot router fails (marked "≈"). |
| Flood | BfG `INSPIRE/NZ` identify, layer 1; `high` = HQhäufig, `medium` = HQ100, `low/extrem` = HQextrem. Empty = `no-data`. Starkregen not covered (said in the UI). |
| Noise | Adapters keyed by the Kreis AGS state prefix: `05` NRW (`laerm_stufe4`, five Lden layers, text/xml), `11` Berlin (`ua_stratlaerm_2022`, four Lden layers, JSON). Max band + dominant source. Other states: `no-data`. |
| Crime | PKS 2025 T01 Kreise, keys `------`, `892000`, `899000`, `435*00`, shipped as `lib/data/pks-2025-kreise.json` (about 25 KB); point → Kreis via the VG250 WFS per listing (no shipped boundary file). National rate = Σ cases ÷ Σ residents of all Kreise. |
| Rent reference | Zensus 2022 1 km grid shipped as a dense gzip'd Uint16 grid (`lib/data/zensus2022-rent-1km.u16.gz`, expected 0.3–0.8 MB; the script refuses more than 1.5 MB) + JSON sidecar. No service is queried: no live-tested Zensus point service exists, and the grid is static until the next census. The 100 m grid (69 MB CSV) is not shipped. |
| Berlin district crime (Could) | Not in phase 3: a second licence regime (CC BY-SA, share-alike on a committed file), a second boundary service and the strongest centre/tourism distortion (Alexanderplatz) for little gain. Possible later. |
| Self-hosted OSM extract | Out of scope; documented in the README as the fallback if the public Overpass servers stay overloaded (`OVERPASS_URL` already allows an own instance). |
| Price check | Price per m² against ≥ 3 other tracked listings of the same mode: same postcode, else same city (browser, no external source). |

```js
// lib/area-http.js — polite HTTP for the area sources: User-Agent, timeout, retries with back-off, minimum spacing.
const { UA } = require("./geo");

const RETRYABLE = new Set([429, 502, 503, 504]);
const MAX_WAIT_MS = 10 * 60 * 1000;
const defaultSleep = ms => new Promise(r => setTimeout(r, ms));

class HttpError extends Error {
  constructor(status, retryAfterMs) { super("HTTP " + status); this.status = status; this.retryAfterMs = retryAfterMs; }
}

// Retry-After in seconds (the only form the public servers send), as milliseconds; null when absent.
function retryAfterMs(r) {
  const v = r && r.headers && typeof r.headers.get === "function" ? r.headers.get("retry-after") : null;
  return v != null && /^\d+$/.test(String(v).trim()) ? Number(v) * 1000 : null;
}

// One request; as = "json" | "text". Throws HttpError on a non-2xx answer and Error("timeout") after `ms`.
async function request(fetchImpl, url, { method = "GET", body, headers = {}, ms = 10000, as = "json" } = {}) {
  const ac = new AbortController();
  const timer = setTimeout(() => ac.abort(), ms);
  try {
    const r = await fetchImpl(url, { method, body, signal: ac.signal, headers: { "User-Agent": UA, ...headers } });
    if (!r.ok) throw new HttpError(r.status, retryAfterMs(r));
    return as === "text" ? await r.text() : await r.json();
  } catch (e) {
    if (ac.signal.aborted && !(e instanceof HttpError)) throw new Error("timeout");
    throw e;
  } finally { clearTimeout(timer); }
}

// Overloaded servers (429/502/503/504), timeouts and network errors are worth another try; 4xx answers and bad data are not.
const isRetryable = e => e instanceof HttpError ? RETRYABLE.has(e.status) : !(e instanceof SyntaxError) && !e.permanent;

// Runs fn, retrying after each delay in turn (a longer Retry-After wins, capped at 10 minutes).
async function withRetry(fn, { delays = [2000], sleep = defaultSleep } = {}) {
  for (let attempt = 0; ; attempt++) {
    try { return await fn(); }
    catch (e) {
      if (attempt >= delays.length || !isRetryable(e)) throw e;
      await sleep(Math.min(MAX_WAIT_MS, Math.max(delays[attempt], e.retryAfterMs || 0)));
    }
  }
}

// Serialises calls and keeps at least minMs between the end of one and the start of the next.
function createSpacer(minMs, { sleep = defaultSleep, clock = Date.now } = {}) {
  let chain = Promise.resolve(), last = -Infinity;
  return fn => {
    const run = chain.then(async () => {
      const wait = last + minMs - clock();
      if (wait > 0) await sleep(wait);
      try { return await fn(); } finally { last = clock(); }
    });
    chain = run.catch(() => {});
    return run;
  };
}

// Query string with %20 for spaces (some OGC servers do not read "+").
const qs = params => Object.entries(params).map(([k, v]) => encodeURIComponent(k) + "=" + encodeURIComponent(v)).join("&");

// A short, safe error text for the listing's area cache (never a stack).
const errorText = e => e instanceof HttpError ? e.message : e && e.message === "timeout" ? "timeout" : e && e.permanent ? e.message : "request failed";

module.exports = { HttpError, request, withRetry, createSpacer, isRetryable, qs, errorText, RETRYABLE };
```

  // Attribution with {date}/{year} filled from an ISO timestamp (or left as the bare text when none is given).
  function attribution(id, fetchedAt) {
    const s = SOURCES[id];
    if (!s) return "";
    const d = typeof fetchedAt === "string" && /^\d{4}-\d{2}-\d{2}/.test(fetchedAt) ? fetchedAt.slice(0, 10).split("-") : null;
    return s.attribution
      .replace("{date}", d ? `${d[2]}.${d[1]}.${d[0]}` : "")
      .replace("{year}", d ? d[0] : String(new Date().getFullYear()))
      .replace(/,\s*$/, "");
  }

  return { SOURCES, ORDER, attribution };
});

#!/usr/bin/env node
// scripts/area-data.js — builds the static area data in lib/data/ from the official downloads.
//   node scripts/area-data.js pks    [--file KR-F-01-T01-Kreise-Faelle-HZ_xls.xlsx]
//   node scripts/area-data.js zensus [--file Zensus2022_Durchschn_Nettokaltmiete.zip]
// Without --file the official file is downloaded. The converters are exported for the tests.
const fs = require("fs");
const path = require("path");
const zlib = require("zlib");

const OUT = path.join(__dirname, "..", "lib", "data");
const UA = "flat-hunt-data/0.1 (+https://github.com/DasMehl/flat-hunt)";
const PKS_URL = "https://www.bka.de/SharedDocs/Downloads/DE/Publikationen/PolizeilicheKriminalstatistik/2025/Kreis/Faelle/KR-F-01-T01-Kreise-Faelle-HZ_xls.xlsx?__blob=publicationFile&v=2";
const ZENSUS_URL = "https://www.destatis.de/static/DE/zensus/gitterdaten/Zensus2022_Durchschn_Nettokaltmiete.zip";
const PKS_MAX_BYTES = 100 * 1024, ZENSUS_MAX_BYTES = 1.5 * 1024 * 1024;

// ---------- zip (stored and deflated entries; no zip64, no encryption) ----------
function readZip(buf) {
  let eocd = -1;
  for (let i = buf.length - 22; i >= Math.max(0, buf.length - 22 - 65535); i--) if (buf.readUInt32LE(i) === 0x06054b50) { eocd = i; break; }
  if (eocd < 0) throw new Error("not a zip file");
  const count = buf.readUInt16LE(eocd + 10), entries = new Map();
  let p = buf.readUInt32LE(eocd + 16);
  if (p === 0xffffffff) throw new Error("zip64 is not supported");
  for (let n = 0; n < count; n++) {
    if (buf.readUInt32LE(p) !== 0x02014b50) throw new Error("broken zip directory");
    const method = buf.readUInt16LE(p + 10), size = buf.readUInt32LE(p + 20);
    const nameLen = buf.readUInt16LE(p + 28), extraLen = buf.readUInt16LE(p + 30), commentLen = buf.readUInt16LE(p + 32);
    const local = buf.readUInt32LE(p + 42), name = buf.toString("utf8", p + 46, p + 46 + nameLen);
    entries.set(name, () => {
      if (buf.readUInt32LE(local) !== 0x04034b50) throw new Error("broken zip entry " + name);
      const start = local + 30 + buf.readUInt16LE(local + 26) + buf.readUInt16LE(local + 28);
      const raw = buf.subarray(start, start + size);
      if (method === 0) return Buffer.from(raw);
      if (method === 8) return zlib.inflateRawSync(raw);
      throw new Error(`zip method ${method} is not supported (${name})`);
    });
    p += 46 + nameLen + extraLen + commentLen;
  }
  return entries;
}

// ---------- xlsx: the first worksheet as rows of strings/numbers ----------
const decodeXml = s => s.replace(/&(#x[0-9a-f]+|#\d+|amp|lt|gt|quot|apos);/gi, (m, e) =>
  e[0] === "#" ? String.fromCodePoint(e[1] === "x" || e[1] === "X" ? parseInt(e.slice(2), 16) : Number(e.slice(1))) : { amp: "&", lt: "<", gt: ">", quot: '"', apos: "'" }[e.toLowerCase()]);
const textOf = xml => decodeXml([...xml.matchAll(/<t(?:\s[^>]*)?>([\s\S]*?)<\/t>/g)].map(m => m[1]).join(""));
const colIndex = ref => [...ref.replace(/\d+$/, "")].reduce((n, ch) => n * 26 + ch.charCodeAt(0) - 64, 0) - 1;

function xlsxRows(buf) {
  const zip = readZip(buf);
  const sheets = [...zip.keys()].filter(k => /^xl\/worksheets\/sheet\d+\.xml$/.test(k)).sort((a, b) => parseInt(a.match(/\d+/)) - parseInt(b.match(/\d+/)));
  if (!sheets.length) throw new Error("no worksheet in the xlsx file");
  const shared = zip.has("xl/sharedStrings.xml") ? [...zip.get("xl/sharedStrings.xml")().toString("utf8").matchAll(/<si>([\s\S]*?)<\/si>/g)].map(m => textOf(m[1])) : [];
  const xml = zip.get(sheets[0])().toString("utf8"), rows = [];
  for (const rm of xml.matchAll(/<row\b[^>]*>([\s\S]*?)<\/row>/g)) {
    const row = [];
    for (const cm of rm[1].matchAll(/<c\b([^>]*?)(?:\/>|>([\s\S]*?)<\/c>)/g)) {
      const attrs = cm[1], inner = cm[2] || "";
      const ref = (/\br="([A-Z]+\d+)"/.exec(attrs) || [])[1], type = (/\bt="(\w+)"/.exec(attrs) || [])[1];
      const v = (/<v>([\s\S]*?)<\/v>/.exec(inner) || [])[1];
      let value = null;
      if (type === "s") value = shared[Number(v)] ?? null;
      else if (type === "inlineStr") value = textOf(inner);
      else if (type === "str") value = v != null ? decodeXml(v) : null;
      else if (v != null) value = Number(v);
      row[ref ? colIndex(ref) : row.length] = value;
    }
    rows.push(Array.from(row, x => x ?? null));
  }
  return rows;
}

// ---------- PKS T01 Kreise → compact JSON ----------
const PKS_KEYS = { total: "------", violent: "892000", street: "899000", burglary: "435*00" };
const norm = v => String(v ?? "").replace(/\s+/g, " ").trim();
const toNum = v => typeof v === "number" ? v : Number(norm(v).replace(/\./g, "").replace(",", "."));

function pksFromRows(rows, { year, generated, minKreise = 390, nationalRange = [3000, 12000] } = {}) {
  const h = rows.findIndex(r => r.some(c => norm(c) === "Schlüssel") && r.some(c => /f(ä|ae)lle/i.test(norm(c))));
  if (h < 0) throw new Error("PKS header row (Schlüssel … Fälle) not found");
  const head = rows[h].map(norm), col = re => head.findIndex(c => re.test(c));
  const c = { key: head.indexOf("Schlüssel"), ags: col(/gemeinde.?schl/i), name: col(/landkreis/i), kind: col(/kreisart/i), cases: col(/f(ä|ae)lle/i), hz: col(/^HZ\b|häufigkeitszahl/i) };
  for (const [k, i] of Object.entries(c)) if (i < 0) throw new Error("PKS column not found: " + k);
  const wanted = Object.fromEntries(Object.entries(PKS_KEYS).map(([k, v]) => [v, k]));
  const kreise = {}, cases = {};
  for (const r of rows.slice(h + 1)) {
    const which = wanted[norm(r[c.key])];
    if (!which) continue;
    const ags = norm(r[c.ags]).padStart(5, "0");
    if (!/^\d{5}$/.test(ags)) continue;
    const k = kreise[ags] || (kreise[ags] = { name: norm(r[c.name]), kind: norm(r[c.kind]) });
    k[which] = toNum(r[c.hz]);
    (cases[ags] || (cases[ags] = {}))[which] = toNum(r[c.cases]);
  }
  const ids = Object.keys(kreise).sort().filter(a => Number.isFinite(kreise[a].total) && kreise[a].total > 0 && Number.isFinite(cases[a].total));
  if (ids.length < minKreise) throw new Error(`only ${ids.length} Kreise found, expected at least ${minKreise}`);
  // Residents per Kreis from the total row (HZ = cases per 100,000 residents); national HZ = Σ cases ÷ Σ residents.
  const pop = Object.fromEntries(ids.map(a => [a, cases[a].total / kreise[a].total * 1e5]));
  const national = {};
  for (const k of Object.keys(PKS_KEYS)) {
    const have = ids.filter(a => Number.isFinite(cases[a][k]));
    national[k] = have.length ? Math.round(have.reduce((s, a) => s + cases[a][k], 0) / have.reduce((s, a) => s + pop[a], 0) * 1e5) : null;
  }
  if (!(national.total >= nationalRange[0] && national.total <= nationalRange[1])) throw new Error("implausible national HZ " + national.total);
  const num = v => Number.isFinite(v) ? Math.round(v) : null;
  return {
    _source: "Bundeskriminalamt, Polizeiliche Kriminalstatistik " + year + ", Tabelle T01 Grundtabelle Kreise (Fälle und Häufigkeitszahlen), " + PKS_URL.replace(/\?.*$/, ""),
    _licence: "Datenlizenz Deutschland – Namensnennung – Version 2.0 (dl-de/by-2-0), https://www.govdata.de/dl-de/by-2-0",
    _attribution: `Bundeskriminalamt, Polizeiliche Kriminalstatistik ${year}, dl-de/by-2-0`,
    _changes: "Converted by scripts/area-data.js: only the keys ------ (all offences), 892000 (violent crime), 899000 (street crime) and 435*00 (residential burglary); HZ rounded to whole numbers; the national value is the sum of all Kreise's cases divided by their residents.",
    _generated: generated || new Date().toISOString().slice(0, 10),
    year,
    columns: ["name", "kind", "total", "violent", "street", "burglary"],
    national,
    kreise: Object.fromEntries(ids.map(a => { const k = kreise[a]; return [a, [k.name, k.kind, num(k.total), num(k.violent), num(k.street), num(k.burglary)]]; }))
  };
}

// The table as JSON with the header first and one Kreis per line (readable diffs).
function pksText(t) {
  const { kreise, ...head } = t;
  return JSON.stringify(head, null, 1).slice(0, -2) + ',\n "kreise": {\n' + Object.entries(kreise).map(([a, v]) => `  ${JSON.stringify(a)}: ${JSON.stringify(v)}`).join(",\n") + "\n }\n}\n";
}

// ---------- Zensus 2022 rent, 1 km grid → dense Uint16 grid (cents per m², 0 = no value), gzip ----------
function zensusGridFromCsv(text, { generated } = {}) {
  const lines = text.replace(/^﻿/, "").split(/\r?\n/).filter(Boolean);
  const head = lines[0].split(";").map(norm);
  const ix = head.findIndex(h => /^x_mp_1km$/i.test(h)), iy = head.findIndex(h => /^y_mp_1km$/i.test(h)), iv = head.findIndex(h => /miete/i.test(h));
  if (ix < 0 || iy < 0 || iv < 0) throw new Error("Zensus columns x_mp_1km / y_mp_1km / …Miete… not found");
  const cells = [];
  let x0 = Infinity, y0 = Infinity, x1 = -Infinity, y1 = -Infinity;
  for (const line of lines.slice(1)) {
    const f = line.split(";");
    const x = Math.floor(Number(f[ix]) / 1000), y = Math.floor(Number(f[iy]) / 1000), v = Number(norm(f[iv]).replace(",", "."));
    if (!Number.isFinite(x) || !Number.isFinite(y) || !Number.isFinite(v) || v <= 0) continue;
    cells.push([x, y, Math.min(65535, Math.max(1, Math.round(v * 100)))]);
    x0 = Math.min(x0, x); y0 = Math.min(y0, y); x1 = Math.max(x1, x); y1 = Math.max(y1, y);
  }
  if (!cells.length) throw new Error("no Zensus cells with a value");
  const width = x1 - x0 + 1, height = y1 - y0 + 1, grid = Buffer.alloc(width * height * 2);
  for (const [x, y, v] of cells) grid.writeUInt16LE(v, ((y - y0) * width + (x - x0)) * 2);
  const meta = {
    _source: "Statistische Ämter des Bundes und der Länder, Zensus 2022, Durchschnittliche Nettokaltmiete je m² (Gitter 1 km), " + ZENSUS_URL,
    _licence: "Datenlizenz Deutschland – Namensnennung – Version 2.0 (dl-de/by-2-0), https://www.govdata.de/dl-de/by-2-0",
    _attribution: "© Statistische Ämter des Bundes und der Länder, Zensus 2022, dl-de/by-2-0",
    _changes: "Converted by scripts/area-data.js into a dense grid of unsigned 16-bit little-endian values (euro cents per m², 0 = no value or suppressed), row by row from the south-west corner, gzip-compressed.",
    _generated: generated || new Date().toISOString().slice(0, 10),
    year: 2022, refDate: "2022-05-15", crs: "EPSG:3035", cellKm: 1,
    file: "zensus2022-rent-1km.u16.gz", x0, y0, width, height, cells: cells.length
  };
  return { meta, gz: zlib.gzipSync(grid, { level: 9 }) };
}

// ---------- CLI ----------
async function download(url) {
  const r = await fetch(url, { headers: { "User-Agent": UA } });
  if (!r.ok) throw new Error(`HTTP ${r.status} for ${url}`);
  return Buffer.from(await r.arrayBuffer());
}
function write(name, data, max) {
  if (data.length > max) throw new Error(`${name} is ${data.length} bytes, more than the ${max} allowed; not written`);
  fs.mkdirSync(OUT, { recursive: true });
  fs.writeFileSync(path.join(OUT, name), data);
  console.log(`wrote lib/data/${name} (${(data.length / 1024).toFixed(1)} KB)`);
}

async function main(argv) {
  const [what] = argv, fi = argv.indexOf("--file"), file = fi >= 0 ? argv[fi + 1] : null;
  if (what === "pks") {
    const buf = file ? fs.readFileSync(file) : await download(PKS_URL);
    const table = pksFromRows(xlsxRows(buf), { year: 2025 });
    write("pks-2025-kreise.json", Buffer.from(pksText(table)), PKS_MAX_BYTES);
    console.log(`${Object.keys(table.kreise).length} Kreise, national HZ ${table.national.total}`);
  } else if (what === "zensus") {
    const zip = readZip(file ? fs.readFileSync(file) : await download(ZENSUS_URL));

const { request, withRetry, qs } = require("./area-http");

const WFS = "https://sgx.geodatenzentrum.de/wfs_vg250";

function kreisUrl(lat, lon) {
  const filter = '<fes:Filter xmlns:fes="http://www.opengis.net/fes/2.0" xmlns:gml="http://www.opengis.net/gml/3.2">' +
    "<fes:Intersects><fes:ValueReference>geom</fes:ValueReference>" +
    `<gml:Point srsName="urn:ogc:def:crs:EPSG::4326"><gml:pos>${lat} ${lon}</gml:pos></gml:Point>` +
    "</fes:Intersects></fes:Filter>";

}

// → { ags: "05111", name: "Düsseldorf", type: "Kreisfreie Stadt" } or null (outside Germany / no polygon).
function parseKreis(json) {
  const f = json && Array.isArray(json.features) ? json.features.find(x => x && x.properties && /^\d{5}$/.test(String(x.properties.ags))) : null;
  return f ? { ags: String(f.properties.ags), name: String(f.properties.gen || ""), type: String(f.properties.bez || "") } : null;
}

// lib/flood.js — mapped river/coastal flood hazard at a point, from the BfG INSPIRE "Natural Risk Zones" service.
const { request, withRetry, qs } = require("./area-http");

const NZ = "https://geoportal.bafg.de/arcgis1/rest/services/INSPIRE/NZ/MapServer/identify";
// Worst first: high = frequent flood (HQhäufig), medium = 100-year flood (HQ100), low = extreme flood (HQextrem).
const LEVELS = ["high", "medium", "low"];

function floodUrl(lat, lon) {
  return NZ + "?" + qs({
    geometry: `${lon},${lat}`, geometryType: "esriGeometryPoint", sr: 4326, layers: "all:1", tolerance: 0,
    mapExtent: `${lon},${lat},${(lon + 0.001).toFixed(6)},${(lat + 0.001).toFixed(6)}`, imageDisplay: "100,100,96", returnGeometry: "false", f: "json"
  });
}

const level = v => { const s = String(v || "").toLowerCase(); return s === "high" ? "high" : s === "medium" ? "medium" : /low|extrem/.test(s) ? "low" : null; };

// → { zones: ["high", "medium", "low"] (subset, worst first) }. An ArcGIS error object throws.
function parseFlood(json) {
  if (!json || json.error || !Array.isArray(json.results)) throw new Error("unexpected flood answer");
  const found = new Set();
  for (const r of json.results) {
    const a = (r && r.attributes) || {};
    if (a.NaturalHazardCategory && !/flood/i.test(a.NaturalHazardCategory)) continue;
    const l = level(a.LikelihoodOfOccurrence);
    if (l) found.add(l);
  }
  return { zones: LEVELS.filter(l => found.has(l)) };
}

async function floodAt(point, fetchImpl, { delays = [2000], sleep, ms = 15000 } = {}) {
  return parseFlood(await withRetry(() => request(fetchImpl, floodUrl(point.lat, point.lon), { ms }), { delays, sleep }));
}

module.exports = { floodUrl, parseFlood, floodAt, LEVELS };

// lib/rent-grid.js — Zensus 2022 average net cold rent of the 1 km grid cell around a point (EPSG:3035 LAEA grid).
const fs = require("fs");
const path = require("path");
const zlib = require("zlib");

const DATA_DIR = path.join(__dirname, "data");
const META_FILE = path.join(DATA_DIR, "zensus2022-rent-1km.json");

// ETRS89 / LAEA Europe (EPSG:3035), GRS80 ellipsoid; formulas from EPSG Guidance Note 7-2 (method 9820).
const A = 6378137, F = 1 / 298.257222101, E2 = F * (2 - F), E = Math.sqrt(E2);
const LAT0 = 52 * Math.PI / 180, LON0 = 10 * Math.PI / 180, FE = 4321000, FN = 3210000;
const q = phi => { const s = Math.sin(phi); return (1 - E2) * (s / (1 - E2 * s * s) - (1 / (2 * E)) * Math.log((1 - E * s) / (1 + E * s))); };
const QP = q(Math.PI / 2), RQ = A * Math.sqrt(QP / 2), BETA0 = Math.asin(q(LAT0) / QP);
const D = A * (Math.cos(LAT0) / Math.sqrt(1 - E2 * Math.sin(LAT0) ** 2)) / (RQ * Math.cos(BETA0));

function toLaea(lat, lon) {
  const phi = lat * Math.PI / 180, dl = lon * Math.PI / 180 - LON0;
  const beta = Math.asin(q(phi) / QP);
  const B = RQ * Math.sqrt(2 / (1 + Math.sin(BETA0) * Math.sin(beta) + Math.cos(BETA0) * Math.cos(beta) * Math.cos(dl)));
  return {
    x: FE + B * D * Math.cos(beta) * Math.sin(dl),
    y: FN + (B / D) * (Math.cos(BETA0) * Math.sin(beta) - Math.sin(BETA0) * Math.cos(beta) * Math.cos(dl))
  };
}

// meta from zensus2022-rent-1km.json, data = the unzipped Uint16LE grid. at(lat, lon) → { cell, eurPerSqm } or null.
function createRentGrid(meta, data) {
  if (data.length !== meta.width * meta.height * 2) throw new Error("rent grid size does not match its metadata");
  return {
    meta,
    at(lat, lon) {
      const { x, y } = toLaea(lat, lon), cx = Math.floor(x / 1000), cy = Math.floor(y / 1000);
      const col = cx - meta.x0, row = cy - meta.y0;
      if (col < 0 || row < 0 || col >= meta.width || row >= meta.height) return null;
      const cents = data.readUInt16LE((row * meta.width + col) * 2);
      return cents ? { cell: `CRS3035RES1000mN${cy * 1000}E${cx * 1000}`, eurPerSqm: cents / 100 } : null;
    }
  };
}

// The shipped grid; null when the files are missing (the rent figure then reports an error).
function loadRentGrid(metaFile = META_FILE) {
  try {
    const meta = JSON.parse(fs.readFileSync(metaFile, "utf8"));
    return createRentGrid(meta, zlib.gunzipSync(fs.readFileSync(path.join(path.dirname(metaFile), meta.file))));
  } catch (e) { return null; }
}

module.exports = { toLaea, createRentGrid, loadRentGrid, META_FILE };

    BBOX: [lat - d, lon - d, lat + d, lon + d].map(v => v.toFixed(6)).join(","), WIDTH: 101, HEIGHT: 101, I: 50, J: 50, INFO_FORMAT: infoFormat
  });

// NRW (Esri text/xml): PixelValue "70111000" → class lower bound 70 dB; "NoData" or nothing → null.
function parseNrw(text) {
  const m = /Classify\.PixelValue="(\d{2})\d*"/.exec(String(text || ""));
  const v = m ? Number(m[1]) : null;
  return v != null && v >= 45 ? v : null;
}

// Berlin (GeoServer JSON): a property like "ab 75 dB(A)" or "55 - 59 dB(A)" → 75 / 55; no feature → null.
function parseBerlin(json) {
  const f = json && Array.isArray(json.features) ? json.features[0] : null;
  if (!f || !f.properties) return null;
  for (const v of Object.values(f.properties)) {
    const m = /(\d{2})(?:[.,]\d+)?\s*(?:-|–|bis|dB)/i.exec(String(v));
    if (m && Number(m[1]) >= 45) return Number(m[1]);
  }
  return null;
}

// lib/area-cache.js — Overpass results cached by rounded position (3 decimals ≈ 100 m) in DATA_DIR/area-cache.json.
const { readJson, writeJsonAtomic } = require("./store");

const DAY = 86400000;
const keyFor = (lat, lon) => `${lat.toFixed(3)},${lon.toFixed(3)}`;

function createAreaCache(file, { now = () => new Date(), ttlMs = 30 * DAY, max = 500 } = {}) {
  let entries = {};
  try { entries = (readJson(file, { entries: {} }) || {}).entries || {}; } catch (e) { entries = {}; } // a broken cache is dropped, not fatal
  let writing = Promise.resolve();
  return {
    get(lat, lon) {
      const e = entries[keyFor(lat, lon)];
      return e && now().getTime() - Date.parse(e.at) < ttlMs ? e : null;
    },
    // Keeps the newest `max` entries; the write is queued and its failure only costs a later re-query.
    set(lat, lon, value) {
      entries[keyFor(lat, lon)] = { at: now().toISOString(), value };
      const keys = Object.keys(entries);
      if (keys.length > max) keys.sort((a, b) => entries[a].at.localeCompare(entries[b].at)).slice(0, keys.length - max).forEach(k => delete entries[k]);
      writing = writing.catch(() => {}).then(() => writeJsonAtomic(file, { entries }));
      return writing.catch(() => {});
    },
    size: () => Object.keys(entries).length
  };
}

module.exports = { createAreaCache, keyFor };

// lib/amenities.js — everyday places around a listing from OpenStreetMap (Overpass), walking minutes from the FOSSGIS foot router.
const { request, withRetry, HttpError } = require("./area-http");
const { distanceKm } = require("../public/criteria");

const OVERPASS_URL = "https://overpass-api.de/api/interpreter";
const FOOT_TABLE = "https://routing.openstreetmap.de/routed-foot/table/v1/driving/";
const CATEGORIES = ["transit", "supermarket", "pharmacy", "doctors", "kindergarten", "school", "park", "playground"];
const RADIUS_M = 1000, STOP_RADIUS_M = 500, PER_CATEGORY = 3, MAX_LINES = 12;
const DETOUR = 1.3, WALK_M_PER_MIN = 80; // straight line × 1.3 at 4.8 km/h when the foot router does not answer

function overpassQuery(lat, lon) {
  const at = (r) => `(around:${r},${lat},${lon})`;
  return `[out:json][timeout:25];
(
  nwr${at(RADIUS_M)}[shop=supermarket];
  nwr${at(RADIUS_M)}[amenity~"^(pharmacy|doctors|kindergarten|school)$"];
  nwr${at(RADIUS_M)}[leisure~"^(park|playground)$"];
  nwr${at(STOP_RADIUS_M)}[public_transport=platform];
)->.poi;
.poi out center tags;
nwr.poi[public_transport=platform]->.p;
(rel(bn.p)[type=route];rel(bw.p)[type=route];);
out body;`;
}

function category(tags) {
  if (tags.public_transport === "platform") return "transit";
  if (tags.shop === "supermarket") return "supermarket";
  if (["pharmacy", "doctors", "kindergarten", "school"].includes(tags.amenity)) return tags.amenity;
  if (["park", "playground"].includes(tags.leisure)) return tags.leisure;
  return null;
}
const lineSort = (a, b) => a.ref.localeCompare(b.ref, "de", { numeric: true });

// Overpass JSON → [{ id, cat, name, lat, lon, meters, lines? }] sorted by straight-line distance. A runtime-error remark throws (retryable).
function parseOverpass(json, point) {
  if (!json || !Array.isArray(json.elements)) throw new Error("unexpected Overpass answer");
  if (json.remark && /error|timed out|out of memory/i.test(json.remark)) throw new HttpError(504);
  const linesOf = new Map();
  for (const r of json.elements.filter(e => e.type === "relation" && e.tags && e.tags.ref)) {
    const line = { ref: String(r.tags.ref).slice(0, 20), mode: String(r.tags.route || "") };
    for (const m of r.members || []) {
      const id = `${m.type}/${m.ref}`;
      if (!linesOf.has(id)) linesOf.set(id, []);
      const list = linesOf.get(id);
      if (!list.some(l => l.ref === line.ref && l.mode === line.mode)) list.push(line);
    }
  }
  const pois = [];
  for (const e of json.elements) {
    if (e.type === "relation" && e.tags && e.tags.type === "route") continue;
    const tags = e.tags || {}, cat = category(tags);
    const lat = e.lat ?? (e.center && e.center.lat), lon = e.lon ?? (e.center && e.center.lon);
    if (!cat || typeof lat !== "number" || typeof lon !== "number") continue;
    const id = `${e.type}/${e.id}`, poi = { id, cat, name: String(tags.name || "").slice(0, 120), lat, lon, meters: Math.round(distanceKm(point, { lat, lon }) * 1000) };
    if (cat === "transit") {
      let lines = linesOf.get(id) || [];
      if (!lines.length && tags.route_ref) lines = String(tags.route_ref).split(/[;,\s]+/).filter(Boolean).map(ref => ({ ref, mode: "" }));
      poi.lines = lines.sort(lineSort).slice(0, MAX_LINES);
    }
    pois.push(poi);
  }
  return pois.sort((a, b) => a.meters - b.meters);
}

// The nearest few per category (straight line): the candidates sent to the foot router.
function candidates(pois) {
  const out = [];
  for (const cat of CATEGORIES) out.push(...pois.filter(p => p.cat === cat).slice(0, PER_CATEGORY));
  return out;
}

async function footTable(point, dests, fetchImpl, { ms = 10000, delays = [2000], sleep } = {}) {
  const coords = [point, ...dests].map(p => `${p.lon.toFixed(6)},${p.lat.toFixed(6)}`).join(";");
  const j = await withRetry(() => request(fetchImpl, `${FOOT_TABLE}${coords}?sources=0&annotations=duration,distance`, { ms }), { delays, sleep });
  if (!j || j.code !== "Ok" || !Array.isArray(j.durations)) throw new Error("unexpected foot router answer");
  return { durations: j.durations[0].slice(1), distances: Array.isArray(j.distances) ? j.distances[0].slice(1) : [] };
}

// Per category the place with the fewest walking minutes, or null when none is within the search radius.
function summarise(cands, walk) {
  const items = {};
  for (const cat of CATEGORIES) {
    let best = null;
    cands.forEach((p, i) => {
      if (p.cat !== cat) return;
      const routed = walk && Number.isFinite(walk.durations[i]);
      const minutes = routed ? Math.max(1, Math.round(walk.durations[i] / 60)) : Math.max(1, Math.round(p.meters * DETOUR / WALK_M_PER_MIN));
      const meters = routed && Number.isFinite(walk.distances[i]) ? Math.round(walk.distances[i]) : Math.round(p.meters * DETOUR);
      if (!best || minutes < best.minutes) best = { name: p.name, minutes, meters, estimated: !routed, ...(p.lines ? { lines: p.lines } : {}) };
    });
    items[cat] = best;
  }
  return items;
}

// → { items, routed } where routed tells whether the walking minutes came from the foot router.
// deps: { fetchImpl, overpass (spacer from area-http), cache, force, overpassUrl, overpassDelays, delays, sleep }
async function amenitiesAt(point, deps) {
  const { fetchImpl, cache, force, sleep } = deps;
  const hit = !force && cache ? cache.get(point.lat, point.lon) : null;
  let pois = hit ? hit.value : null;
  if (!pois) {
    const body = "data=" + encodeURIComponent(overpassQuery(point.lat, point.lon));
    pois = await deps.overpass(() => withRetry(async () => parseOverpass(await request(fetchImpl, deps.overpassUrl || OVERPASS_URL, {
      method: "POST", body, headers: { "Content-Type": "application/x-www-form-urlencoded" }, ms: 60000
    }), point), { delays: deps.overpassDelays || [30000, 60000, 120000], sleep }));
    pois = pois.map(({ lat, lon, ...p }) => ({ ...p, lat: +lat.toFixed(6), lon: +lon.toFixed(6) }));
    if (cache) await cache.set(point.lat, point.lon, pois);
  }
  // Distances are re-measured from this listing's exact point (the cache entry may come from a neighbour within ~100 m).
  pois = pois.map(p => ({ ...p, meters: Math.round(distanceKm(point, p) * 1000) })).sort((a, b) => a.meters - b.meters);
  const cands = candidates(pois);
  let walk = null;
  if (cands.length) { try { walk = await footTable(point, cands, fetchImpl, { delays: deps.delays, sleep }); } catch (e) { walk = null; } }
  return { items: summarise(cands, walk), routed: !!walk || !cands.length, cached: !!hit };
}

module.exports = { overpassQuery, parseOverpass, candidates, footTable, summarise, amenitiesAt, CATEGORIES, OVERPASS_URL };

// lib/area.js — computes the area facts for one point. Every figure carries its status, source, area level and fetch time.
const { errorText } = require("./area-http");
const { lookupKreis } = require("./kreis");
const { crimeFor } = require("./crime");
const { floodAt } = require("./flood");
const { noiseAt } = require("./noise");
const { amenitiesAt } = require("./amenities");

// status: "ok" (value found), "no-data" (the source has nothing for this point — never read as "no risk"), "error" (lookup failed).
async function figure(source, level, now, fn) {
  const base = { source, level };
  try {
    const value = await fn();
    return value ? { status: "ok", ...base, fetchedAt: now().toISOString(), ...value } : { status: "no-data", ...base, fetchedAt: now().toISOString() };
  } catch (e) {
    return { status: "error", ...base, fetchedAt: now().toISOString(), error: errorText(e) };
  }
}
const permanent = msg => Object.assign(new Error(msg), { permanent: true });

// deps: { fetchImpl, now, crimeTable, rentGrid, overpass, cache, force, overpassUrl, delays, overpassDelays, sleep }
async function computeArea(point, deps) {
  const { fetchImpl, now } = deps, opts = { delays: deps.delays, sleep: deps.sleep };
  const area = { lat: point.lat, lon: point.lon };

  area.kreis = await figure("bkg-vg250", "point", now, () => lookupKreis(point, fetchImpl, opts));
  const kreis = area.kreis.status === "ok" ? { ags: area.kreis.ags, name: area.kreis.name } : null;
  const needKreis = () => { if (area.kreis.status === "error") throw permanent("Kreis unknown"); };

  area.flood = await figure("bfg-nz", "point", now, async () => {
    const { zones } = await floodAt(point, fetchImpl, opts);
    return zones.length ? { zones, worst: zones[0], dataYear: 2019 } : null;
  });

  area.noise = await figure(null, "point", now, async () => {
    needKreis();
    const n = kreis ? await noiseAt(point, kreis.ags, fetchImpl, opts) : null;
    return n ? { ...n, dataYear: 2022 } : null;
  });

  area.crime = await figure("bka-pks", "kreis", now, () => {
    needKreis();
    return kreis ? crimeFor(kreis, deps.crimeTable) : null;
  });

  area.rent = await figure("zensus-rent", "cell-1km", now, () => {
    if (!deps.rentGrid) throw permanent("rent grid missing");
    const r = deps.rentGrid.at(point.lat, point.lon);
    return r ? { ...r, year: 2022, refDate: deps.rentGrid.meta.refDate } : null;
  });

  area.amenities = await figure("osm", "walk", now, async () => {

    return { items: r.items, routing: r.routed ? "osm-foot" : "estimate", cached: r.cached };
  });

  area.computedAt = now().toISOString();
  return area;
}

// lib/area-job.js — background queue: one listing at a time, never in a request. The result is applied only if the
// listing still exists at the same coordinates (a moved listing has been queued again).
function createAreaQueue({ state, persist, compute }) {
  const queue = [], forced = new Set();
  let running = null, looping = false, waiters = [];

  async function loop() {
    while (queue.length) {
      const id = queue.shift();
      running = id;
      const c = state.listings[id];
      if (c && typeof c.lat === "number" && typeof c.lon === "number") {
        const point = { lat: c.lat, lon: c.lon }, force = forced.delete(id);
        let area = null;
        try { area = await compute(point, { force }); } catch (e) { area = null; }
        const cur = state.listings[id];
        if (area && cur && cur.lat === point.lat && cur.lon === point.lon) {
          const prev = cur.area;
          cur.area = area;
          try { await persist(); }
          catch (e) { if (cur.area === area) { if (prev === undefined) delete cur.area; else cur.area = prev; } }
        }
      }
      running = null;
    }
    looping = false;
    waiters.splice(0).forEach(r => r());
  }

  return {
    // force: skip the Overpass cache (on-demand recompute).
    enqueue(id, { force = false } = {}) {
      if (force) forced.add(id);
      if (!queue.includes(id)) queue.push(id);
      if (!looping) { looping = true; Promise.resolve().then(loop); }
    },
    drop(id) { const i = queue.indexOf(id); if (i >= 0) queue.splice(i, 1); forced.delete(id); },
    status: () => ({ queued: [...queue], running }),
    // Resolves when the queue is empty (tests; graceful shutdown).
    idle: () => looping ? new Promise(r => waiters.push(r)) : Promise.resolve()
  };
}

// Listings with coordinates whose area is missing or belongs to other coordinates (start-up backfill).
const needsArea = c => typeof c.lat === "number" && typeof c.lon === "number" && (!c.area || c.area.lat !== c.lat || c.area.lon !== c.lon);

module.exports = { createAreaQueue, needsArea };

  // → { own, median, n, level: "postcode" | "city", diff (share above (+) or below (−) the median) } or null.
  function priceCheck(l, others) {
    const own = pricePerSqm(l);
    if (own == null) return null;
    const pool = (others || []).filter(o => o !== l && o.id !== l.id && o.mode === l.mode && !o.gone);
    const median = vals => { const v = vals.sort((a, b) => a - b), m = v.length >> 1; return v.length % 2 ? v[m] : (v[m - 1] + v[m]) / 2; };
    const tries = [["postcode", o => l.postcode && o.postcode === l.postcode], ["city", o => cityKey(l) && cityKey(o) === cityKey(l)]];
    for (const [level, same] of tries) {
      const vals = pool.filter(same).map(pricePerSqm).filter(v => v != null);
      if (vals.length >= UNDERPRICED_MIN_OTHERS) { const med = median(vals); return { own, median: med, n: vals.length, level, diff: Math.round((own / med - 1) * 100) / 100 }; }
    }
    return null;
  }

  //   everyday = 10 × mean over six groups of walking points (≤ 5 min 1, ≤ 10 min 0.75, ≤ 15 min 0.5, ≤ 20 min 0.25, else or none 0);

  //   minus flood (HQhäufig 3, HQ100 2, only HQextrem 0.5), noise Lden (≥ 70 dB 2, ≥ 65 1.5, ≥ 60 1, ≥ 55 0.5),
  //   crime in the Kreis vs the national rate (≥ 1.5 × 1, ≥ 1.2 × 0.5). Figures with no data or an error count 0.
  //   value = round(everyday − deductions), clamped to 0–10. Null until the amenities are known.
  const AREA_GROUPS = [["transit"], ["supermarket"], ["pharmacy"], ["doctors"], ["kindergarten", "school"], ["park", "playground"]];
  const walkPoints = m => m == null ? 0 : m <= 5 ? 1 : m <= 10 ? 0.75 : m <= 15 ? 0.5 : m <= 20 ? 0.25 : 0;
  const FLOOD_DEDUCT = { high: 3, medium: 2, low: 0.5 };
  function areaRating(area) {
    const am = area && area.amenities;
    if (!am || am.status !== "ok" || !am.items) return null;
    const groups = AREA_GROUPS.map(cats => {
      const mins = cats.map(c => am.items[c] && am.items[c].minutes).filter(v => typeof v === "number");
      const minutes = mins.length ? Math.min(...mins) : null;
      return { group: cats.join("|"), minutes, points: walkPoints(minutes) };

    const everyday = Math.round(groups.reduce((s, g) => s + g.points, 0) / groups.length * 100) / 10;
    const parts = [{ key: "everyday", value: everyday, groups }];

    if (fl && fl.status === "ok" && FLOOD_DEDUCT[fl.worst]) parts.push({ key: "flood", value: -FLOOD_DEDUCT[fl.worst], worst: fl.worst });
    if (no && no.status === "ok" && no.max != null) { const d = no.max >= 70 ? 2 : no.max >= 65 ? 1.5 : no.max >= 60 ? 1 : no.max >= 55 ? 0.5 : 0; if (d) parts.push({ key: "noise", value: -d, max: no.max }); }
    const ratio = cr && cr.status === "ok" && cr.ratio ? cr.ratio.total : null;
    if (ratio != null) { const d = ratio >= 1.5 ? 1 : ratio >= 1.2 ? 0.5 : 0; if (d) parts.push({ key: "crime", value: -d, ratio }); }
    const value = Math.max(0, Math.min(10, Math.round(parts.reduce((s, p) => s + p.value, 0))));
    return { value, parts };
  }
